# PROVE HUMAN — 프로토타입 v0.1

AI에게 넘어간 세상, 마지막 섬 판게아의 검문소. 구조선에서 내린 생존자가 사람인지 위장 AI인지 가려내 통과 또는 사살한다. 30일을 버티면 교대.

## 실행 방법

1. Unreal Engine 5.6 이상과 Visual Studio 2022(C++ 게임 개발 워크로드)를 설치한다.
2. `Pangaea.uproject`를 더블클릭 → "모듈을 빌드하시겠습니까?"에서 **예**.
3. 에디터가 열리면 **Play**. 에셋이 하나도 없어도 코드가 검문소, 조명, NPC, UI를 전부 만든다.

5.7 이상이라면 `.uproject` 우클릭 → Switch Unreal Engine version.

## 조작

| 상황 | 키 |
|---|---|
| 이동 / 둘러보기 | WASD / 마우스 |
| 착석·기립 (부스 의자 근처) | E |
| 도구: 체온·맥박계 / 손전등 / 채혈 키트 / 엑스레이 | 1 / 2 / 3 / 4 |
| 심문 질문 4개 | Z / X / C / V |
| 통과 | P |
| 사살 (2초 안에 두 번) | K, K |

착석 중에는 마우스 커서로 버튼도 누를 수 있다.

## 구조

| 파일 | 역할 |
|---|---|
| `PangaeaData.cpp` | 일차별 규칙, 해금 일정, NPC 생성기, 대사 |
| `PangaeaText.cpp` | 지역·직업·암구호·징후 이름 등 번역 대상 문구 |
| `InspectionSession.*` | 창구 앞 1명 검사 로직(도구 결과, 질문) |
| `PangaeaGameMode.*` | 하루 루프, 판정, 밤 정산, 시설, 엔딩, 저장, 월드 배치 |
| `NpcActor.*` | NPC 임시 몸, 열화상·엑스레이 연출, 동공 반응, 사살·혈흔 |
| `PangaeaCharacter.*` | 1인칭 이동, 착석, 손전등 확대, 입력 |
| `SPangaeaHUD.*` | 전체 UI(Slate) |

정답과 모든 검사 결과는 NPC가 생성될 때 코드에서 정해진다. 연출(메타휴먼, 애니메이션)은 나중에 바꿔도 판정 로직은 그대로다.

## 직접 확인할 테스트 목록

- [ ] 빌드가 되는지, Play 시 타이틀이 뜨는지
- [ ] 한글이 깨지지 않고 보이는지
- [ ] 새 게임 → 브리핑 → 근무 시작 → 의자로 걸어가 E로 착석되는지
- [ ] NPC가 부두 쪽에서 걸어와 창구 앞에 서는지, 얼굴이 창구 높이에 보이는지
- [ ] 1번: 열화상 색으로 바뀌고 수치가 기록되는지 / 다시 누르면 원래대로
- [ ] 2번: 시점이 얼굴로 확대되고 손전등이 켜지며 동공이 줄어드는지
- [ ] 3번: 7일차 전엔 막혀 있는지, 키트가 줄어드는지
- [ ] 4번: 엑스레이 게이트를 지은 뒤 골격이 보이는지
- [ ] Z~V 질문이 3개까지만 되는지(심문실 건설 후 4개)
- [ ] P: NPC가 옆 출구로 걸어 나가고 다음 사람이 오는지
- [ ] K 두 번: NPC가 쓰러지고 혈흔이 남는지 / 피 표현 끄면 혈흔이 없는지
- [ ] 10분이 지나거나 인원이 끝나면 밤 보고서가 뜨는지, 정답과 징후가 맞게 나오는지
- [ ] 휴무일에 "하루 쉬기" → 정산 → 시설 관리 흐름
- [ ] 시설 건설 후 월드에 건물이 생기는지, 다음 날에도 남아 있는지
- [ ] 종료 후 이어하기가 그날 아침부터 시작되는지
- [ ] 야간 근무 날 조명이 어두워지는지
- [ ] 30일 도달, 침투 8회, 사기 0에서 각 엔딩이 뜨는지
